# 前端开发约定

- React/Vite 源码位于 src/，静态资源位于 public/，合成状态与组件测试位于 tests/。
- 保持各主题的公共布局、键盘语义、可见焦点和减少动态效果设置。
- 保留未保存草稿、固定资料和版本、只读、并发、取消与迟到结果保护；阅读和预览不触发保存或模型任务。
- 功能测试使用合成资料和模拟 API，不操作用户文稿、资料或模型配置。
- 部署地址及运维访问主机由环境变量显式配置；默认只允许本机回环入口。
- 不提交本机配置、依赖、构建输出、截图录制报告或历史验收产物。
- 使用帮助保持只读，不提供演示材料的添加或安装操作；正常资料导入入口保持可用。
