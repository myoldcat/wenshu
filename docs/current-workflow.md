# 从资料到文稿

文枢将资料阅读、知识积累与文稿写作放在同一工作台。模型输出是辅助内容，结构检查、作者确认或引用登记不等于事实已经核实；重要表述应回到原文判断。

## 先准备资料与模型

1. 在系统设置中添加实际可用的模型连接，填写接口地址、模型名称及必要凭据，保存后按需测试并设为默认。连接测试会向所选服务发起请求。
2. 使用本地文件选择、拖放或网页链接导入资料。重复文件按完整内容识别，重新导入不应覆盖人工分类、收藏、已读和写作选材。
3. 原文入库与模型加工分别进行。按实际需要启用自动处理或手动生成摘要、翻译和分类；没有可用模型时仍可阅读已保存原文。

## 阅读与积累

在文库中用全部、收藏和已选标签浏览资料，并结合目录、来源、日期和检索缩小范围。日期目录优先采用明确的发表日期，无法确定时回退导入日期。阅读可切换原文、中文或对照，人工分类与锁定译文继续保留。

知识图谱用于发现词条、关系和相关来源。构建前核对资料范围与当前结果，必要时选择构建全部待构建资料；后台分批继续，取消保留已有成功结果。词条和关系仍须回查原文，不能作为独立事实证明。

删除文档前先查看对文稿文字、图片引用的影响，再明确确认。删除来源不会改写已有文稿正文或历史；查看相关引用时可能提示来源不可用。

## 六步写作

| 步骤 | 如何操作 |
| --- | --- |
| 主题设定 | 填写主题、要求、题目与长度，选择结构、文风和写作方式；明确要求的结构优先于模板 |
| 资料筛选 | 核对人工选择与系统推荐，确认本稿使用的资料范围；后续更改文库勾选不等于更改本稿 |
| 写作纲要 | 查看或修改章标题、目标及顺序，确认后再生成正文；已有正文或锁定内容可能限制重新生成 |
| 正文编写 | 按方式一次成文或逐章推进；保存人工修改，逐章确认后可继续，全文预览保留明确的正文确认入口 |
| 文章配图 | 可选择不配图，之后仍可重新开始；手动选图确认位置，自动配图按实际结果核对，不强行配满 |
| 检查校验 | 按需要开始检查、明确人工确认或跳过；分清过期、跳过和已检查状态，再导出 HTML、Word 或 PDF |

智能化写作会连续处理已授权流程；运行期间可以查看已保存内容，需要编辑时按页面提示取消或中断。交互式可逐步调整。生成和保存失败时先查看实际状态，避免重复提交或覆盖未保存稿。

严谨模式围绕所选资料组织内容，拓展模式也不得编造事实、数字或来源。引用、配图和检查报告对应具体保存版本；修改后应重新核对相关内容。

## 保存、退出与帮助

未保存草稿可能随关闭页面丢失，重要修改应显式保存。服务端关闭浏览器不会停止后台任务，需要停止生成时先在页面取消或中断；Windows 应用按退出提示处理任务后正常关闭。

使用指南按服务端或 Windows 本地版固定展示，只读且不把帮助或演示资料加入文库。正常文件、拖放和网页导入继续可用，旧库中的文档、文稿、人工修改及历史不会因移除演示功能而自动删除。

完整图文操作见[服务端版](../resources/presets/manual/user-guide-server.html)或[Windows 本地版](../resources/presets/manual/user-guide-windows.html)。
