# Windows 安装版使用

Windows 本地版以独立窗口运行文枢，适用于 Windows 10／11 x64。用户程序不要求预装 Python、Node.js 或 Docker；本地运行也不代表自带离线大模型，摘要、翻译与写作仍需配置可用模型。

## 打开与退出

运行所获安装程序，按提示完成当前用户安装，再从桌面或开始菜单打开。程序默认安装到 `%LOCALAPPDATA%\Programs\Wenshu`。已有 WebView2 Runtime 时复用，缺失时按安装提示使用微软工具补装，需要网络和系统允许安装。

使用指南固定展示 Windows 本地版，仅供阅读。首次启动不自动导入帮助、学习资料或示例文稿。资料通过正常文件选择、拖放和网页链接导入。

退出前保存修改，按提示等待或停止后台任务，再正常关闭应用。不要在任务运行或退出尚未完成时覆盖程序、复制数据库或搬移资料。

## 资料与备份

文档、原文、文稿、模型配置及日志保存在 `%LOCALAPPDATA%\Wenshu`，独立于安装目录。升级或卸载程序不应清除该目录；仍建议操作前自行备份。

正常退出后整体备份资料目录，不只复制运行中的数据库主文件。换电脑或 Windows 账户后，受当前账户保护的模型密钥可能需要重新输入。安装包和模型权重不能代替资料备份。

## 常见问题

- 窗口未打开：先核对 WebView2 是否可用，以及目录和账户是否允许运行程序。
- 没有摘要或译文：查看模型配置、自动处理开关和入库进度；原文入库成功不代表模型加工完成。
- 正文无法编辑：核对是否正在生成、已完成只读或章节锁定，按页面提示处理。
- 导出或校验有提醒：回查当前保存版本、来源与未解决事项，不把跳过或人工确认当作自动核实。

详细操作见[Windows 本地版图文指南](../resources/presets/manual/user-guide-windows.html)。免安装使用见[绿色版](windows-portable.md)。
