# Windows 绿色版使用

将整个绿色版压缩包解压到有写权限的文件夹，双击最外层 `Wenshu.exe`；不要在压缩包内运行，也不要单独启动或拆散 `app/` 中的程序。

## 目录

| 路径 | 内容 |
| --- | --- |
| `app/` | 应用程序与内置依赖，作为整体维护 |
| `data/` | 文档、原文、文稿、模型配置与任务记录 |
| `profile/` | 窗口偏好、WebView2 缓存、日志与临时文件 |
| `tools/` | 需要时使用的 WebView2 补装工具 |

绿色版不运行文枢安装程序，不创建文枢卸载项或开始菜单快捷方式。已有 WebView2 Runtime 时复用；缺失时按提示补装，仍需网络及系统权限。系统和共享组件可能保留自身缓存。

使用指南只读，启动不自动导入帮助或示例。资料仍通过文件选择、拖放或网页链接正常导入；已有库中的内容与人工修改继续保留。

## 移动与升级

先保存文稿，等待导入结束并正常退出，再移动或备份整个绿色目录。待处理上传可能关联原路径，不要在排队或处理中移动文件夹。

升级前完整备份，在新目录解压新版，然后在应用停止状态下迁入原 `data/` 与 `profile/`。不要运行中覆盖 SQLite 数据库，也不要把旧 `app/` 覆盖到新版。

模型密钥由当前 Windows 账户保护，跨电脑或账户后通常需要重新输入。安装版与绿色版共用单实例和本地端口保护，不同时运行。删除整个绿色目录也会删除其中资料，应先备份需要保留的内容。

完整操作见[Windows 本地版图文指南](../resources/presets/manual/user-guide-windows.html)。
