# 只读使用指南

应用保留一个“使用指南”入口，服务端应用固定展示服务端版，Windows 桌面应用展示本地版，与访问者浏览器系统或地址无关。

- [服务端部署版图文指南](../resources/presets/manual/user-guide-server.html)
- [Windows 本地版图文指南](../resources/presets/manual/user-guide-windows.html)

手册作为只读资源显示，启动和浏览均不向文库导入帮助或演示资料，不创建文稿，也不调用模型。窗口保留正文标题、关闭、滚动与缺失重试，不提供添加示例功能。

正常文件选择、拖放和网页链接导入继续可用。移除演示导入功能不删除旧库中的文档、文稿、人工修改或历史，帮助更新也不覆盖已入库的旧手册快照。截图中的合成资料仅说明操作，不代表真实调查结论。
