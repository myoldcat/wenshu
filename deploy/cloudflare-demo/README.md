# 共享口令入口 Worker

`worker.mjs` 为应用的外部入口提供口令验证、主机约束、会话签名和登录限速。它不包含实际域名、账户、路由、上游地址或口令。

使用时将 `wrangler.example.jsonc` 复制到仓库外，按自己的账户填写实际配置：

- `main` 指向本项目的 `worker.mjs`；使用外部配置文件时应提供可解析的完整路径。
- `DEMO_HOST` 为唯一允许的完整主机名，不含协议、路径或通配符；缺失或非法时拒绝访问。
- Route 必须精确覆盖该主机的全部路径，并启用失败时关闭访问；上游与通道也由实例维护者单独配置。
- `LOGIN_LIMITER` 是每个实例自己的限速绑定；示例命名空间必须按实际资源替换。
- `DEMO_PASSWORD` 使用平台 Secret 保存，不写入配置文件、代码、命令参数或日志。

示例配置没有活动路由，不应直接用于部署。默认关闭独立预览入口和日志观测，程序不在异常时透传请求。共享口令授予进入应用的权限，应用内的数据隔离由业务服务负责。

会话使用 Secure、HttpOnly、SameSite=Strict 的主机 Cookie；签名绑定配置主机。主机、密码或签名上下文改变后旧会话失效。所有表单写入保留同源与 CSRF 检查，运维页面仍由应用自身的独立主机白名单控制。

运行合成单元测试：

```powershell
node --test deploy/cloudflare-demo/worker.test.mjs
```

实际账户、域名、绑定、路由、通道、口令和切换记录应仅保存在仓库外，不随源码发布。
