文枢绿色版（Windows 10/11 x64）

开始使用
1. 将整个压缩包解压到有写权限的文件夹。
2. 双击根目录的 Wenshu.exe，不要直接运行 app 文件夹内的程序。
3. 首次启动建立独立资料库，不自动导入帮助、学习文章或示例文稿；使用指南作为只读资源打开。
4. 系统设置中自行配置模型。绿色版不包含大模型；本地模型或远程模型均可按需连接。

目录
  Wenshu.exe  绿色启动器，双击此文件
  app\        完整程序和内置依赖，请勿拆散或修改
  data\       资料、原文、文稿、模型配置及任务记录
  profile\    窗口偏好、WebView2缓存、运行日志与临时文件
  tools\      微软官方WebView2运行库补装工具

无需运行文枢安装程序，不创建开始菜单快捷方式或卸载注册项，也不修改用户/系统环境变量。
默认的资料、缓存和临时文件都写入当前解压目录。Windows及共享运行库自身仍可能维护系统缓存。
不要在压缩包内直接运行，不要把目录放在无写权限的系统位置或只读介质。

WebView2
已有WebView2时直接复用，不重复安装。
缺失时，启动器会提示打开 tools\MicrosoftEdgeWebview2Setup.exe；点击确定后由微软工具联网补装。
这一步安装的是共享运行库，仍需系统允许安装。绿色包不包含固定版浏览器。
补装被企业策略拒绝时，请联系电脑管理员；反复运行文枢安装器不能解决系统策略限制。

资料与帮助
资料通过正常的文件选择、拖放或网页链接导入，不提供演示材料专用导入功能。
使用指南按应用类型显示，浏览不写入文库、不创建文稿或调用模型。
升级保留旧资料库中的文档、文稿、人工修改、历史导入记录与旧手册快照，不自动删除或覆盖。

数据、移动与升级
本包不携带开发者数据库、模型凭证或模型权重，不自动读取或迁移安装版的用户资料。
退出前先保存文稿，等待后台任务结束。等所有导入完成并正常退出后，才移动、备份或删除整个文件夹。
不要在入库排队/处理中移动文件夹，否则尚未完成的上传任务可能需要重新导入对应文件。
升级时先备份，将新包解压到新目录，再在退出状态下把原 data 和 profile 文件夹复制过去。
不要把旧 app 覆盖到新版，也不要在运行时复制SQLite数据库。
模型密钥由当前Windows账户DPAPI保护；换电脑或换账户后通常需要重新输入密钥。
绿色版与安装版共用单实例保护及本地端口，不能同时运行两份。
删除程序时，请先备份 data 中需要保留的资料与文稿；删除整个绿色目录也会删除其中的数据。

故障
出现拒绝访问：确认已经完整解压，整个文件夹对当前用户可写。
窗口未打开：查看 profile\logs\desktop.log、api.log、worker.log。
发布包版本和签名以实际交付为准；构建成功不代表所有目标机器的安装与交互兼容性已经通过验证。
